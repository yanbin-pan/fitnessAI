# Waitlist landing page (Claude version)

A one-page neumorphic site that reuses the app's real low-poly companions from `web/src/companions`.

To build it, run this once in this folder: `npm i esbuild react react-dom three@0.186.1`. Then run `node build.mjs`. It writes a single self-contained `zabaione-landing.html`.

The effects in `src/fx.tsx` are hand-made versions of these React Bits effects: BlurText, RotatingText, CountUp, TextType, SpotlightCard, Magnet, ClickSpark, ScrollReveal and DotGrid.
